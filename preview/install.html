התקנת Parabula לטלפון

המסלול המומלץ הוא לפתוח את אפליקציית המובייל הקנונית של הריפו, לבדוק שהיא נטענת תקין, ואז להוסיף אותה למסך הבית.

שלב 1 — פתח את אפליקציית המובייל הקנונית פתח את אפליקציית המובייל דרך הקישור הראשי. אם הכול תקין, תראה את רשימת הדפים, חיפוש, נושאים, ניווט, וכפתור preview-before-print / PDF.
פתח אפליקציית מובייל שכבת compat ישנה פתח שער אפליקציה
שלב 2 — הוסף למסך הבית בדפדפן בטלפון בחר בתפריט של הדפדפן ואז חפש אפשרות כמו "הוסף למסך הבית" או "התקן אפליקציה". הניסוח משתנה בין דפדפנים.
שלב 3 — בדוק הדפסה / PDF מרכז ההדפסה מאפשר לבחור דפים אמיתיים מהריפו ולפתוח אותם ברצף. משם הדפדפן עצמו מספק Print / Save as PDF.
פתח מרכז הדפסה
שלב 4 — בדוק תיעוד ורצף עבודה אם תרצה לבדוק מה כבר נוסף ומה עדיין פתוח, עבור למסמכי ה-STATE. אלה מסמכי הרצף הזמניים עד לסנכרון מלא עם PROJECT_RULES.md.
