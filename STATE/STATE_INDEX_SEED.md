Status: initial seed only. This is not a complete index of all STATE files.

## Purpose

Begin classifying central STATE documents by authority level so future work does not confuse current truth with historical evidence.

## Authority labels

| Label | Meaning |
|---|---|
| CURRENT_PLANNING | Current planning document created for PR5. |
| CURRENT_EVIDENCE | Current or recent evidence still relevant. |
| HISTORICAL | Historical context; useful but not overriding live code. |
| VALIDATION_REPORT | Validator/runtime result; interpret with date and scope. |
| OPEN_GATE | Known incomplete validation or decision. |
| SUPERSEDED_OR_CONFLICTING | May conflict with current live code; inspect before use. |
| UNKNOWN | Not reviewed yet. |

- `styles/a4-base.css`
- `mobile-app.*`
- `preview/print.*`
