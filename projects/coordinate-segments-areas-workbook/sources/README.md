# sources/ — קליטת חוברת המקור

תיקייה זו היא הנתיב הקנוני שבו המערכת מצפה לקבל את קובץ המקור:

```
sources/שטחים והיקפים במערכת הצירים.pdf
```

## המצב הנוכחי

הקובץ **אינו נמצא בריפו**, ולכן 30 שאלות המקור אינן משולבות בחוברת, והפרויקט
פועל במצב העשרה בלבד. `npm run validate` מדפיס אזהרה חד־משמעית על כך בכל
ריצה, ואוכף ש־`STATUS.md` מצהיר על החסר במפורש. אין לסמן את שלב שילוב
המקור כהושלם ואין להמציא שאלות ולתארן כשאלות מקור.

## מה קורה כשהקובץ יונח כאן

1. `npm run validate` יפסיק להזהיר, וידרוש במקום זאת ש־`STATUS.md` יפסיק
   להצהיר "שאלות המקור אינן משולבות" — כלומר יכריח לעדכן את שלב השילוב.
2. תוכנית השילוב המוכנה מראש:
   - מיפוי 30 השאלות לרצף: `research/source-map.md` (סעיף 3).
   - תוכנית עמודי השילוב: `content/unit-04-quadrilaterals-composite.md`
     (עמודי תוכנית 60–62: שאלות 20–30, כולל תיקוני עריכה הדורשים אישור יניב).
   - העמודים החדשים ייכנסו בתוך מעטפת 80–90 העמודים המתוכננת, בהעתקה
     נאמנה למקור לפי כללי `CLAUDE.md` §4.
3. סרטוטי המקור ייבנו מחדש וקטורית בדיוק מדיד, לפי אותו תהליך שבו נבנו
   94 הסרטוטים הקיימים.

## מה אסור

- אין להעתיק לכאן קובץ אחר בשם הזה.
- אין לשחזר את החוברת מהזיכרון — רק הקובץ האמיתי שימסור יניב.
