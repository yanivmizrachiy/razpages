# מסלול ביצוע — חוברת יחס

מסמך זה הוא מסלול העבודה המחייב להמרת 48 דפי נושא יחס מעמודי תמונה לעמודי HTML חיים, בלי לשנות את רצף הספר או את תוכן המקור.

## תחום העבודה

- עמודים קנוניים: `עמוד-272.html` עד `עמוד-319.html`.
- מספור מקומי: 1–48.
- מקור עריכה: `sources/lovable/ratio-workbook/src/`.
- תמונות `assets/ratio/page-001.png` עד `page-048.png` נשארות תוצר audit בלבד ואינן תוכן קנוני.

## סדר הביצוע

1. הגנה על המצב הקיים ובדיקות baseline.
2. נטרול הייבוא ההרסני שמחליף HTML בתמונות.
3. יצירת exporter קנוני שמפיק HTML חי מרכיבי React.
4. איחוד גופנים ל־Rubik מקומי ואיחוד שכבת העיצוב.
5. יצירת רכיבי תשובה תקניים: יחס, דרך חישוב, תשובה סופית, יחידה וטקסט.
6. מעבר תוכני על 48 העמודים בחמש קבוצות.
7. בדיקות A4, RTL/LTR, נגישות, מובייל, הדפסה ורגרסיה.
8. Pull Request נפרד לבדיקה לפני מיזוג ל־`main`.

## שערי השלמה

- 48 עמודים בדיוק, במספור גלובלי 272–319 ומקומי 1–48.
- אין `ratio-import-image` בדפים הקנוניים.
- כל הטקסט ניתן לבחירה ולהעתקה.
- כל סרטוט משמעותי נשאר SVG.
- Rubik נטען מקומית ומשמש בפועל.
- לכל שאלה חישובית יש מקום לדרך ולתשובה סופית.
- כל תשובת יחס בנויה משתי תיבות וסימן `:` מודפס ביניהן.
- אין overflow, חיתוך או הקטנת גופן כדי להכניס תוכן.
- הכותרת התחתית הקבועה מופיעה בכל עמוד.
- הניווט הקודם/הבא נשאר רציף בתוך הספר המלא.
- כל בדיקות ה־CI ובדיקות היחס הייעודיות עוברות.
